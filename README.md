# Deep Learning & AI — Learning Repository

A collection of hands-on implementations, experiments, problem-solving exercises, and learning notes covering the foundations of Artificial Intelligence, Machine Learning, Deep Learning, and Large Language Models.

This repository documents my learning journey through practical implementations, from fundamental mathematical concepts and neural networks to modern Transformer architectures and language models.

The main goal is to understand how these systems work internally by implementing algorithms, exploring their mathematics, experimenting with different approaches, and documenting the learning process.

## What You'll Find

This repository brings together different areas of AI and computer science:

- **Deep Learning & Neural Networks** — Neural network fundamentals, forward propagation, backpropagation, activation functions, optimization, and gradient descent.
- **Transformers & Attention** — Self-attention, positional encoding, multi-head attention, Transformer architecture, and related concepts.
- **Large Language Models (LLMs)** — GPT architecture, tokenization, language modeling, autoregressive generation, and the fundamentals of modern language models.
- **Machine Learning** — Core algorithms, model evaluation, classification, regression, ensemble methods, and model validation.
- **Mathematics for AI** — Linear algebra, calculus, probability, statistics, and numerical methods.
- **Natural Language Processing (NLP)** — Character-level language modeling, tokenization, and text generation.
- **Python & SQL** — Programming exercises, algorithmic problem-solving, and database queries.

## Deep-ML Explorer

The repository also includes a companion Streamlit application in the `visualizer/` directory.

The Deep-ML Explorer helps build intuition around Machine Learning and mathematical concepts through:

- Worked numerical examples.
- Step-by-step mathematical explanations.
- Interactive visualizations.
- Concept exploration beyond the existing notebooks.

### Run Locally

```bash
cd visualizer
pip install -r requirements.txt
streamlit run app.py
```

An optional Gemini API key can be configured to explore additional concepts beyond the pre-built library.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/aboudrari/Deep-ML-Solutions.git
cd Deep-ML-Solutions
```

Install the dependencies required for the notebooks:

```bash
pip install numpy pandas matplotlib torch jupyter
```

Open any notebook using Jupyter or VS Code.

```bash
jupyter notebook
```

Some notebooks may require additional dependencies depending on the topic.

## Learning Approach

My approach throughout this repository is based on:

1. Understanding the mathematical foundations behind each concept.
2. Breaking down algorithms into smaller components.
3. Implementing solutions and models step by step.
4. Experimenting with different approaches and configurations.
5. Visualizing results to build intuition.
6. Documenting observations, challenges, and lessons learned.

The focus is not simply on getting an implementation to work, but on understanding why it works and how its individual components fit together.
